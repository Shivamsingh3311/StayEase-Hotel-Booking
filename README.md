
# StayEase - Hotel Booking Website

StayEase is a responsive hotel booking website built with HTML, CSS,
and vanilla JavaScript. It is a beginner-friendly frontend project
for learning web development.

## Features

- Responsive design for desktop, tablet, and mobile.
- Hotel cards with photos, locations, prices, and ratings.
- Search hotels by destination.
- Select check-in and check-out dates.
- Choose the number of guests.
- Interactive booking summary.
- Automatic calculation of demo stay costs.
- Booking confirmation dialog.
- No frontend frameworks required.

## Technologies Used

- HTML5 - Website structure
- CSS3 - Styling, layout, and responsive design
- JavaScript - Search, validation, and booking interactions

## How to Run

1. Create a folder named `StayEase`.
2. Create the four files listed above.
3. Copy each code section into its corresponding file.
4. Save all files in the same folder.
5. Open `index.html` in your browser.

You can also open the folder in Visual Studio Code and use the
Live Server extension to preview the website.

## How to Use

1. Open the website.
2. Enter a destination such as Goa, Jaipur, or Manali.
3. Choose your check-in and check-out dates.
4. Select the number of guests.
5. Click Search Hotels.
6. Click Book Now on a hotel.
7. Review the booking summary and confirm the demo booking.

## Important Limitations

This project is a frontend demonstration only.

- It does not connect to a hotel inventory or booking API.
- Hotel names, prices, ratings, and availability are sample data.
- Booking confirmations do not create real reservations.
- No payment processing or user account system is included.
- Hotel images and fonts require an internet connection.
